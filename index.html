IRL Network · Linux Player

Turn any screen into an IRL Player.

One command turns a small Linux device into a dedicated IRL Network screen. It starts by itself when powered on, plays fullscreen with nothing else on the display, and recovers on its own if anything goes wrong. No technical skills needed.

LIVE

Paste this in the device's terminal

curl -fsSL https://linux-player.theirlnetwork.com/install.sh | sudo bash

The player appears on screen right away — and on every power-on after that.

Choosing your device and system

What to install, which Raspberry Pi to pick, and what to have ready before you run the command. Short version: Raspberry Pi OS (64-bit) on any supported Pi, connected to the internet — the command installs everything else by itself.

The system to install

Install Raspberry Pi OS (64-bit) with the official Raspberry Pi Imager. The Lite version is the best choice — it has no desktop, which the player doesn't need, so it boots faster and stays lighter. The full Desktop version works too. The only hard rule: it must say 64-bit — the 32-bit version won't work.

Raspberry Pi 5 (or 3 / 4 / Zero 2 W)

The normal boards — ready to use out of the box. Flash a microSD card with the Imager, put it in, connect the screen and power, done. The Pi 5 is the fastest option and uses a micro-HDMI cable and a USB-C power supply (use the official 27 W one — weak phone chargers cause random restarts).

Compute Module 5 (CM5)

The same brain as a Pi 5, but as a bare module: it needs a carrier board (like the official CM5 IO Board) to get its HDMI, USB and power connectors. Two kinds exist: CM5 Lite uses a microSD card — flash it exactly like a normal Pi. CM5 with built-in storage (eMMC) has no card to flash: connect the carrier board to your computer by USB and use Raspberry Pi's rpiboot tool so the Imager can write to it. Also check your CM5 variant has Wi-Fi — some don't, and those need a network cable. After the system boots, everything on this page is identical for both.

Ready before you run the command

Nothing to install by hand — the command sets up the player and everything it needs. Just make sure: the Pi is running Raspberry Pi OS 64-bit, it's online (set the Wi-Fi name and password in the Imager before flashing, or plug in a network cable), and you know the username and password you chose in the Imager. Tip: also enable SSH in the Imager's settings — it lets someone help you remotely later without touching the device.

Starting from zero with a Raspberry Pi

Never touched a Raspberry Pi before? This is everything, start to finish. You need a Raspberry Pi, a microSD card (16 GB or more), a screen with an HDMI cable, and Wi-Fi or a network cable.

Put the system on the memory card

On your computer, install Raspberry Pi Imager and insert the microSD card. Choose your Pi model, then the system: Raspberry Pi OS (64-bit). Before writing, the Imager asks about settings — set your Wi-Fi name and password there so the Pi connects to the internet by itself. Two more settings are worth doing right there: give the device its own name (for example shop-window-1) so you can always tell your players apart, and turn on Raspberry Pi Connect so you can reach the device over the internet later — the Imager signs you in through your browser. Then write the card.

Plug everything in

Put the card in the Pi. Connect the screen with the HDMI cable, plug in a keyboard (just for the setup), and connect the power last. The Pi turns on by itself — give it a minute on first start.

Open the terminal

When the Pi finishes starting, open the Terminal — the black window where you can type. On the desktop version it's in the top menu bar; if you only see text on a black screen, you're already there — just log in with the username and password you chose in the Imager.

Paste the command

Copy the command from the top of this page, paste it into the terminal (right-click → Paste, or Ctrl+Shift+V) and press Enter. It may ask for your password — type it and press Enter (nothing shows while typing, that's normal). Then wait a few minutes.

Done — it runs itself

The player fills the screen. You can unplug the keyboard and mouse now. From here on, the Pi is an IRL screen: give it power and it plays.

It looks after itself

Once installed, the device maintains itself. You don't check on it, update it, or fix it — it does all of this on its own.

Updates itself

Every hour (and on every start) the device checks for a new version and installs it automatically. New features and fixes arrive on their own — there's nothing to download or click.

Recovers from crashes

If the player ever stops unexpectedly, it's started again within 3 seconds — usually faster than anyone notices.

Notices a frozen picture

The device watches its own screen. A playing stream always moves — so if the picture stays completely still for 5 minutes, it knows something is stuck and restarts the player by itself.

Heals its internet connection

If the Wi-Fi drops and doesn't come back — say the router rebooted — the device notices, restarts its own connection, and reconnects. No more "turn it off and on" calls when the internet hiccups.

Stays secure

Security updates for the system itself are installed automatically at night, quietly in the background. The device stays safe for years without anyone touching it.

Reboots as a last resort

If restarting the player doesn't help, the device does what you would do: it turns itself off and on again. And if the whole system ever locks up, a hardware chip inside the Raspberry Pi forces a reboot — even software can't stop it.

Everyday use

There are no settings to worry about. These five things cover everything.

Turning it on and off

Just plug the power in — the player starts by itself. To turn it off, unplug it. That's safe; nothing needs shutting down first.

Getting out of the player

Plug in a keyboard and press Ctrl+Alt+P to leave the player and use the device normally. Press it again to bring the player back on top.

Updating

It updates itself. The device checks for a new version every hour and on every start, and installs it automatically. You never need to do anything — but running the install command again also works.

If it ever freezes

It fixes itself. The device notices a stuck picture within minutes, restarts the player, and reboots itself if that's not enough. If you don't want to wait: unplug the power, wait five seconds, plug it back in.

Manage it from anywhere

With the free Raspberry Pi Connect service you can reach your device over the internet from any web browser — no cables, no network setup. The easiest way to turn it on is while flashing the card: the Raspberry Pi Imager's settings include Raspberry Pi Connect — enable it there and every device is connected from its very first start. On a device that's already running, open the terminal (Ctrl+Alt+P to exit the player) and type sudo apt install rpi-connect-lite (the Desktop version of the system already includes it), then rpi-connect signin and follow the link it prints to sign in with a free Raspberry Pi account. Either way, all your devices appear by name at connect.raspberrypi.com, wherever they are.

If something looks wrong

The three things people actually run into, and the fix for each.

The screen is black
Check the HDMI cable and that the screen is on the right input. Still black? During install, make sure you picked Raspberry Pi OS (64-bit) in the Imager — the 32-bit version won't work. Re-flash the card with the 64-bit one and install again.
There's no sound
Most screens play sound through the HDMI cable automatically. If yours doesn't, press Ctrl+Alt+P to exit the player, log in, type sudo raspi-config, choose System Options → Audio and pick your speaker. Then press Ctrl+Alt+P to go back.
It says it's offline / nothing plays
The device lost internet. If it's on Wi-Fi, make sure the router is on and in range — the player reconnects by itself. To change to a new Wi-Fi network, the easiest way is to re-flash the card with the Imager (enter the new Wi-Fi there) and run the install command again.

Removing the player

Want the device back to normal? Press Ctrl+Alt+P to exit the player, log in, then paste this and press Enter:

curl -fsSL https://linux-player.theirlnetwork.com/uninstall.sh | sudo bash
