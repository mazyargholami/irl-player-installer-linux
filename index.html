IRL Network · Screen Player

Turn a Raspberry Pi into a dedicated IRL Player screen

One command installs the player and locks it fullscreen on the top layer. No desktop, no notifications, no screensaver — the app boots straight to the screen and restarts itself if it ever crashes.

Raspberry Pi 3 / 4 / 5 / Zero 2 W Raspberry Pi OS 64-bit (Lite or Desktop) Internet during install

Install

  1. Flash Raspberry Pi OS 64-bit with Raspberry Pi Imager and boot the Pi. Lite is enough — no desktop needed.
  2. Open a terminal on the Pi (or SSH into it) and run:
    $ curl -fsSL https://mazyargholami.github.io/irl-player-installer-linux/install.sh | sudo bash
  3. That's it. The player starts fullscreen right away and on every boot from now on.

The installer checks it is really running on a Raspberry Pi with a 64-bit OS before touching anything, then installs the player package, the kiosk compositor, and the boot service.

On top ↔ normal: the hotkey

The player is on top by default — at boot and after install. With a keyboard plugged into the Pi:

Ctrl + Alt + P — switch between kiosk mode (fullscreen, on top) and the normal layer (console login, or the desktop if one is installed). Press it again to put the player back on top.

The hotkey reads raw keyboard input, so it works no matter what is on screen. Without a keyboard attached, nothing can interrupt the player.

Manage the player

From a terminal or over SSH:

# is it running? $ sudo systemctl status irl-player-kiosk # watch live logs $ journalctl -u irl-player-kiosk -f # restart the app $ sudo systemctl restart irl-player-kiosk # stop until next boot $ sudo systemctl stop irl-player-kiosk # same as pressing Ctrl+Alt+P $ sudo irl-kiosk-toggle

Uninstall

Removes the service, the hotkey, the package, and the kiosk user:

$ curl -fsSL https://mazyargholami.github.io/irl-player-installer-linux/uninstall.sh | sudo bash

If the Pi originally booted to a desktop, bring it back afterwards with sudo systemctl enable --now lightdm.

How it works

PieceWhat it does
irl-player.debThe player app, installed to /opt/irl-player with its dependencies via apt.
cageA kiosk compositor that runs exactly one app, maximized, permanently on top. There is no desktop underneath — no window can ever cover the player.
irl-player-kiosksystemd service that boots straight into the player on tty1 as an unprivileged user and restarts it within 3 seconds if it crashes.
irl-player-hotkeySmall background service that listens for Ctrl+Alt+P and toggles the layer.

Screen blanking is disabled at install, and there is no screensaver or lock screen in the kiosk environment — the display stays on 24/7.

Troubleshooting

  • Black screen after install — check the logs: journalctl -u irl-player-kiosk -e. The most common cause is a 32-bit OS image; the player needs Raspberry Pi OS 64-bit.
  • No audio — the kiosk runs outside a desktop session, so sound goes through ALSA directly. Pick the right output in sudo raspi-config → System Options → Audio.
  • Mouse cursor or title bar on screen — re-run the install command; current versions hide the cursor with a transparent theme and run the app borderless.
  • Stuck and no keyboard? — SSH in and run sudo systemctl stop irl-player-kiosk, or power-cycle the Pi; it recovers cleanly.
